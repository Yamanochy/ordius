# Приложение Ordius

Рабочее приложение для водителей, механиков и офиса. Устанавливается на телефон с сайта (PWA, «На экран Домой»),
работает без связи: смены, фото документов, заправки и задачи копятся на телефоне и уходят на сервер сами.

| Что | Где |
|---|---|
| Исходники | `src/` — React 18, без UI-библиотек; стили и токены — `src/styles.css` (те же, что в демо и на сайте) |
| Собранное | `dist/` — его раскладывает `ordius-deploy` на сервере в `pb_public`; PocketBase отдаёт по адресу https://app.ordius.ru |
| Проверка | `test/e2e.mjs` — сквозной прогон в браузере на настоящем PocketBase |

## Как устроено

- **Данные** — PocketBase JS SDK, тот же адрес, что и приложение. Права проверяет сервер (правила и хуки в `backend/`),
  приложение лишь не показывает лишнего.
- **Без связи** — `src/lib/outbox.js`: всё, что вносит водитель, сначала ложится в очередь в IndexedDB (вместе с фото),
  потом по порядку уходит на сервер: сразу, при появлении сети, при возвращении в приложение, раз в 30 секунд.
  Приложение само задаёт `id` новой записи, поэтому повторная отправка не создаёт дубль. Смена создаётся черновиком,
  потом строки и фото, и только последним шагом — «на проверку»: руководитель не увидит смену без фото.
  Счётчик неотправленного — в шапке; «Ещё → Неотправленное» — список с ошибками.
- **Чтение без связи** — `src/lib/data.js`: последний ответ сервера хранится на телефоне и показывается сразу,
  свежий подтягивается следом.
- **Фото** — сжимаются на телефоне до 1600 px (обычно 250–500 КБ), закрытые файлы открываются по временному токену.
- **Вход** — по номеру и паролю или по звонку (`/api/ordius/phone/*`): человек звонит на показанный номер,
  запасной путь — звонок робота и 4 последние цифры.
- **Роли** — офис (владелец, руководитель, диспетчер, бухгалтер) видит «Сводку», смены всех, людей, ведомость;
  водитель — свой заработок, смены, деньги; механик — задачи и ТО.

## Разработка

```bash
cd app
npm install
VITE_PB_URL=http://127.0.0.1:8090 npm run dev     # PocketBase с backend/ должен быть запущен
npm run build                                     # после любой правки — собрать и закоммитить dist/
```

Проверка (нужен PocketBase той же версии, что на сервере, и Playwright с Chromium):

```bash
cd app && npm run build && cd ..
PB_BIN=/путь/к/pocketbase node app/test/e2e.mjs
```

Сценарий: водитель регистрируется звонком (заглушка SMS.ru) и принимает приглашение; вносит смену с фото путевого
и показаниями одометра; вторую смену — без связи, она ждёт в очереди и уходит, когда связь появилась, без дублей;
руководитель подтверждает одну смену и возвращает другую с причиной; ведомость; водитель видит заработок и
записывает заправку. Скриншоты экранов — в `app/test/shots/`. В GitHub это делает `.github/workflows/app-tests.yml`,
там же проверяется, что `dist/` собран из текущих исходников.
