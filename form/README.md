# Форма записи на пилот — ordius.ru

Форма в блоке «Идёт запись на пилот» на лендинге отправляет заявку в облачную функцию
Yandex Cloud. Функция записывает заявку в хранилище в России и присылает карточку на
ordius.info@yandex.ru. Один файл `index.js`, без сторонних библиотек.

Пока в `index.html` не задан адрес функции (`FORM_ENDPOINT`), формы на сайте не видно —
вместо неё кнопка «Записаться на пилот» ведёт в Telegram. Сайт не ломается.

## Текущее развёртывание (22.10.2026)

- Функция `ordius-form` (ID `d4elmq1rdrc7toicisor`), каталог `default`, Node.js 22, 15 с, 128 МБ.
- Ссылка для вызова: `https://functions.yandexcloud.net/d4elmq1rdrc7toicisor` — публичная.
- Бакет `ordius-leads-48213`, сервисный аккаунт `ordius-form` с ролью `storage.uploader` на каталог.
- Проверено тестовыми заявками: запись в бакет и письмо на ordius.info@yandex.ru работают.
- На сайте ещё **не включена**: `FORM_ENDPOINT` вписывается после подачи уведомления в Роскомнадзор.

## Что делает функция

- Принимает заявки только со страниц ordius.ru (проверка Origin/Referer).
- Отсекает спам-ботов: невидимое поле-ловушка и слишком быстрая отправка (быстрее 2,5 с).
- Проверяет поля: имя, телефон (+7… в любом написании), техника, способ учёта, галочка согласия.
- Записывает заявку в бакет `forms/<дата>/…json` вместе с отметкой о согласии
  (когда дано, какая редакция) — это доказательство согласия по ч. 3 ст. 9 152-ФЗ.
- Присылает письмо «Ordius: заявка на пилот #K7M2QX — Иван Петров».
- Если хранилище или почта временно недоступны, заявка всё равно принимается, пока работает хотя бы одно из двух.
  Если недоступно всё — сайт покажет посетителю запасные контакты.
- Персональные данные в логи не пишутся, IP-адрес не сохраняется.

Проверка: `node form/test.js` (33 проверки, включая отправку письма по TLS на тестовый SMTP-сервер).

## Запуск — по шагам

### 1. Пароль приложения для почты ordius.info@yandex.ru
1. Войти в ящик ordius.info@yandex.ru → шестерёнка → «Все настройки» → **«Почтовые программы»**.
2. Включить «С сервера imap.yandex.ru по протоколу IMAP», проверить, что отмечено
   «Пароли приложений и OAuth-токены» → «Сохранить изменения».
3. id.yandex.ru → «Безопасность» → **«Пароли приложений»** → в строке «Почта» нажать «+».
4. Название `Форма Ordius` → «Далее» → скопировать пароль. Он показывается один раз —
   сразу вставьте его в переменную `MAIL_PASS` (шаг 5). Никому не пересылайте, в чат тоже.

### 2. Yandex Cloud и платёжный аккаунт
1. console.yandex.cloud → войти через Яндекс ID ordius.info@yandex.ru. Если попросит создать организацию —
   создать (имя `Ordius`), в ней сам появится каталог `default`.
2. Сервис «Billing» → вкладка «Аккаунт» → «Создать аккаунт» → тип «Физическое лицо», страна Россия →
   проверить почту и телефон → привязать карту российского банка (для проверки заблокируют 11 ₽ и вернут) → «Создать».
   Пробного периода нет, но бесплатный уровень действует.
3. Если консоль пишет, что создание ресурсов ограничено (облако с 11.10.2026 в аварийном режиме) —
   сделайте скриншот и пришлите, решим.

### 3. Бакет для заявок
1. Каталог `default` → сервис «Object Storage» → «Создать бакет».
2. «Имя бакета»: `ordius-leads-` + 5–6 случайных цифр (имя уникально во всём Yandex Cloud, точку не ставить).
3. «Максимальный размер»: включить «Установить максимальный размер бакета» → `1 ГБ` (страховка от счетов).
4. «Публичный доступ» — для чтения объектов, списка объектов и настроек везде **«С авторизацией»** (не «Для всех»!).
5. «Класс хранилища» — «Стандартное». Шифрование и метки не трогать → «Создать бакет».
6. Открыть бакет → вкладка «Настройки» → вкладка «Жизненный цикл» → «Настроить» → включить «Статус»,
   «Описание»: `Удаление заявок через год`, «Префикс» **оставить пустым** (правило на весь бакет),
   действие `Expiration` → «Количество дней», «Срок срабатывания» `365` → «Сохранить». Это срок хранения из политики.

### 4. Сервисный аккаунт
1. Сервис «Identity and Access Management» → «Создать сервисный аккаунт» → имя `ordius-form` → «Создать».
2. Роль назначается отдельно: вернуться в каталог `default` → вкладка «Права доступа» → «Настроить доступ» →
   раздел сервисных аккаунтов → выбрать `ordius-form` → «Добавить роль» → **`storage.uploader`** → «Сохранить».
   Нужны «Права доступа» именно **каталога**, не самого сервисного аккаунта (адрес вида `/service-account/…/resource-acl` — не та страница).
3. Если консоль выдаёт ошибку — то же через «Cloud Shell» (меню слева):
   ```
   yc iam service-account get ordius-form
   yc resource-manager folder add-access-binding default --role storage.uploader --service-account-id <id из первой команды>
   yc resource-manager folder list-access-bindings default
   ```

### 5. Функция
1. Сервис «Cloud Functions» → «Создать функцию» → имя `ordius-form` → «Создать».
2. На странице функции — кнопка создания версии в редакторе → среда **Node.js 22** →
   галочку «Добавить файлы с примерами кода» оставить → «Продолжить».
3. Способ — «Редактор кода». Открыть файл `index.js`, выделить всё (Ctrl+A), удалить и вставить
   всё содержимое `form/index.js` из репозитория (на GitHub: файл → кнопка «Copy raw file»).
4. Точка входа `index.handler`, таймаут **`15`** с, память `128 МБ`,
   **сервисный аккаунт — `ordius-form`**.
5. «Переменные окружения» → добавить:
   - `BUCKET` — имя бакета из шага 3;
   - `MAIL_USER` — `ordius.info@yandex.ru`;
   - `MAIL_PASS` — пароль приложения из шага 1.
6. «Сохранить изменения». Дождаться, пока версия соберётся (статус «Активна»).
7. Вкладка «Обзор» → включить **«Публичная функция»** → скопировать «Ссылку для вызова»
   вида `https://functions.yandexcloud.net/d4e…`.

### 6. Подключить форму к сайту
Пришлите ссылку из шага 5.7 — она не секретная (видна в коде любой страницы, защищает функцию
проверка сайта и фильтр спама). Я впишу её в `FORM_ENDPOINT` в `index.html` **после подачи уведомления
в Роскомнадзор** (ч. 1 ст. 22 152-ФЗ), и форма появится на ordius.ru.

### 7. Проверка
1. На ordius.ru в блоке «Идёт запись на пилот» заполнить форму своими данными, отметить согласие, отправить.
2. Должно появиться «Заявка принята, номер заявки #…».
3. Через минуту на ordius.info@yandex.ru — письмо с карточкой. В бакете — папка `forms/<дата>/` с файлом.

### 8. Почта: порядок и уведомления
- В приложении «Яндекс Почта» на телефоне войти в ordius.info@yandex.ru и включить уведомления — так заявка придёт пушем.
- Настройки → «Правила обработки писем» → «Создать правило»: если тема содержит «Ordius: заявка» —
  положить в папку «Заявки Ordius».
- Раз в месяц удалять из этой папки письма старше 1 года (срок из политики).

## Если что-то не работает

Смотреть «Логи» функции в консоли Yandex Cloud.

- Сайт пишет «Не получилось отправить», в логах ничего нет — функция не публичная (шаг 5.6) или в `FORM_ENDPOINT` не та ссылка.
- `BUCKET not set` — нет переменной; `no IAM token` — не выбран сервисный аккаунт; `storage put error 403` — у аккаунта нет роли `storage.uploader`.
- `mail error SMTP AUTH: 535` — неверный пароль приложения или не включён доступ почтовых программ (шаг 1).
- `partial delivery` — заявка принята, но дошла только в одно место (почта или хранилище); номер заявки в строке лога.
