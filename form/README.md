# Форма записи на пилот — ordius.ru

Форма в блоке «Идёт запись на пилот» на лендинге отправляет заявку в облачную функцию
Yandex Cloud. Функция записывает заявку в хранилище в России и присылает карточку на
ordius.info@yandex.ru. Один файл `index.js`, без сторонних библиотек.

Пока в `index.html` не задан адрес функции (`FORM_ENDPOINT`), формы на сайте не видно —
вместо неё кнопка «Записаться на пилот» ведёт в Telegram. Сайт не ломается.

## Что делает функция

- Принимает заявки только со страниц ordius.ru (проверка Origin/Referer).
- Отсекает спам-ботов: невидимое поле-ловушка и слишком быстрая отправка (быстрее 2,5 с).
- Проверяет поля: имя, телефон (+7… в любом написании), техника, способ учёта, галочка согласия.
- Записывает заявку в бакет `forms/<дата>/…json` вместе с отметкой о согласии
  (когда дано, какая редакция) — это доказательство согласия по ч. 3 ст. 9 152-ФЗ.
- Присылает письмо «Ordius: заявка на пилот #K7M2QX — Иван Петров».
- Если хранилище или почта временно недоступны, заявка всё равно принимается, пока работает хотя бы одно из двух.
  Если недоступно всё — сайт покажет посетителю запасные контакты.
- Персональные данные в логи не пишутся, IP-адрес не сохраняется.

Проверка: `node form/test.js` (33 проверки, включая отправку письма по TLS на тестовый SMTP-сервер).

## Стоимость

0 ₽: всё укладывается в бесплатный уровень Yandex Cloud (1 млн вызовов функций, 1 ГБ хранения,
10 000 записей в месяц). Платёжный аккаунт с картой всё равно нужен — без него облако не работает.

## Запуск — по шагам

### 1. Пароль приложения для почты ordius.info@yandex.ru
1. Войти в ящик ordius.info@yandex.ru → шестерёнка → «Все настройки» → **«Почтовые программы»**.
2. Включить «С сервера imap.yandex.ru по протоколу IMAP», проверить, что отмечено
   «Пароли приложений и OAuth-токены» → «Сохранить изменения».
3. id.yandex.ru → «Безопасность» → **«Пароли приложений»** → в строке «Почта» нажать «+».
4. Название `Форма Ordius` → «Далее» → скопировать пароль. Он показывается один раз —
   сразу вставьте его в переменную `MAIL_PASS` (шаг 5). Никому не пересылайте, в чат тоже.

### 2. Yandex Cloud и платёжный аккаунт
1. console.yandex.cloud → войти через Яндекс ID ordius.info@yandex.ru (или свой — как удобнее).
2. Создать платёжный аккаунт: физическое лицо, привязать карту.
3. Если консоль пишет, что создание ресурсов ограничено (облако с 11.10.2026 в аварийном режиме) —
   сделайте скриншот и пришлите, решим.

### 3. Бакет для заявок
1. Слева «Object Storage» → «Создать бакет».
2. Имя: `ordius-leads-` + 5–6 случайных цифр (имя должно быть уникальным во всём Yandex Cloud).
3. Доступ на чтение объектов, к списку объектов и к настройкам — **«Ограниченный»**.
   Класс хранилища — «Стандартное». Максимальный размер — 1 ГБ → «Создать бакет».
4. Открыть бакет → «Жизненный цикл» → «Настроить» → «Добавить правило»: префикс **оставить пустым**,
   «Удаление объектов» через `365` дней → «Сохранить». Это срок хранения из политики.

### 4. Сервисный аккаунт
«Identity and Access Management» → «Сервисные аккаунты» → «Создать сервисный аккаунт» →
имя `ordius-form`, роль **`storage.uploader`** → «Создать».

### 5. Функция
1. «Cloud Functions» → «Создать функцию» → имя `ordius-form` → «Создать».
2. «Редактор»: среда **Node.js 22** → «Продолжить». Способ — «Редактор кода».
   В файл `index.js` вставить всё содержимое `form/index.js` из репозитория.
3. Точка входа `index.handler`, таймаут **`15`** с, память `128 МБ`,
   **сервисный аккаунт — `ordius-form`**.
4. «Переменные окружения» → добавить:
   - `BUCKET` — имя бакета из шага 3;
   - `MAIL_USER` — `ordius.info@yandex.ru`;
   - `MAIL_PASS` — пароль приложения из шага 1.
5. «Сохранить изменения».
6. Вкладка «Обзор» → включить **«Публичная функция»** → скопировать «Ссылку для вызова»
   вида `https://functions.yandexcloud.net/d4e…`.

### 6. Подключить форму к сайту
Пришлите ссылку из шага 5.6 — она не секретная (видна в коде любой страницы, защищает функцию
проверка сайта и фильтр спама). Я впишу её в `FORM_ENDPOINT` в `index.html`, и форма появится на ordius.ru.

### 7. Проверка
1. На ordius.ru в блоке «Идёт запись на пилот» заполнить форму своими данными, отметить согласие, отправить.
2. Должно появиться «Заявка принята, номер заявки #…».
3. Через минуту на ordius.info@yandex.ru — письмо с карточкой. В бакете — папка `forms/<дата>/` с файлом.

### 8. Почта: порядок и уведомления
- В приложении «Яндекс Почта» на телефоне войти в ordius.info@yandex.ru и включить уведомления — так заявка придёт пушем.
- Настройки → «Правила обработки писем» → «Создать правило»: если тема содержит «Ordius: заявка» —
  положить в папку «Заявки Ordius».
- Раз в месяц удалять из этой папки письма старше 1 года (срок из политики).

## Если что-то не работает

Смотреть «Логи» функции в консоли Yandex Cloud.

- Сайт пишет «Не получилось отправить», в логах ничего нет — функция не публичная (шаг 5.6) или в `FORM_ENDPOINT` не та ссылка.
- `BUCKET not set` — нет переменной; `no IAM token` — не выбран сервисный аккаунт; `storage put error 403` — у аккаунта нет роли `storage.uploader`.
- `mail error SMTP AUTH: 535` — неверный пароль приложения или не включён доступ почтовых программ (шаг 1).
- `partial delivery` — заявка принята, но дошла только в одно место (почта или хранилище); номер заявки в строке лога.
