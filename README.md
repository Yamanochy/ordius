# Ordius

Учёт смен, техники, ремонтов и зарплаты водителей для автопарков и владельцев спецтехники.

## Что лежит в репозитории

- `index.html` — временная главная страница (будет заменена посадочной).
- `demo/` — собранное демо, открывается по адресу `/demo/`. Не править руками — собирается из `demo-src`.
- `demo-src/` — исходники демо (React + Vite).

## Как пересобрать демо

```bash
cd demo-src
npm install
npm run build   # результат попадает в ../demo
```

Все данные в демо вымышленные и хранятся только в браузере посетителя.
